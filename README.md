# InternNova Official Homepage Redesign
**Student:** Om Vijay Rothe

## Project overview
A student-created responsive homepage redesign concept using HTML, CSS and vanilla JavaScript. Sections include navigation, hero, about/approach, internship domains, learning journey, community CTA, FAQ and footer.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in your browser.
3. Optional: run `python -m http.server 8000` in this folder and open `http://localhost:8000`.

No build tools or package installation are required. Google Fonts need an internet connection; fallback fonts are included.

## Files
- `index.html` — full homepage
- `style.css` — responsive styling and animation
- `script.js` — mobile navigation and dynamic year
- `screenshots/` — illustrative design previews

## Before submission
- Visit https://internnova.co.in/ and write your own notes about the current site’s UI/UX.
- Test the site on desktop and mobile.
- Capture fresh screenshots from your browser. The included previews are illustrative mockups, not screenshots of a deployed site.
- Verify current program details on InternNova's official site; this concept avoids claiming unverified testimonials, placement outcomes, or statistics.

## Publish with GitHub Pages
1. Create a GitHub repository named `internnova-homepage-redesign`.
2. Upload the files from this folder.
3. Open **Settings → Pages**.
4. Select deployment from the `main` branch and `/ (root)`, then save.
5. Open the published URL and test it before submitting.
